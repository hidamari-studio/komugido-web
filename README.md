# こむぎ堂 Web サイト

街のパン屋「こむぎ堂」の Web サイトです。制作・運用はひだまり制作室が担当しています。

## 構成

| 場所 | 中身 |
| --- | --- |
| `index.html` | トップ（お知らせ・営業時間） |
| `menu.html` | パンの一覧（季節のパンは月ごとに入れ替わる） |
| `access.html` | お店の場所・定休日 |
| `assets/css/` | 見た目 |
| `assets/img/` | 写真（パンの写真は季節ごとに差し替える） |
| `src/components/` | 部品（ヘッダー・お知らせ・パンのカード）と、その story |
| `screenshots/` | story を撮った画像。部品の見た目が変わると、ここの画像も変わる |

## 部品の見た目を直すとき

部品は Storybook で、状態ごと（通常・売り切れ・写真なし・スマホ幅など）に確かめます。

```bash
npm install
npx playwright-core install chromium   # 初めてのときだけ（画像を撮るブラウザ）
npm run storybook                      # http://localhost:6006/ で部品を見る
```

直したら、送る前に story の画像を撮り直して、画像も同じコミットに入れてください。

```bash
npm run shoot   # screenshots/ の画像を撮り直す
```

レビューでは、画像の変更前・変更後を比べて、どの状態の見た目が変わったかを確かめます。
部品を直したときは、`menu.html` などのページの同じ部分も同じ形に揃えます。

## よくある依頼

- お知らせの追加（臨時休業・新商品）
- 季節のパンの入れ替え（文言と写真）
- 営業時間・定休日の変更
- 部品の見た目の調整（売り切れの出し方、ボタンの目立たせ方など）

依頼はこむぎ堂さんからチャットで届きます（スクリーンショットに赤字で指示が入っていることが多い）。
